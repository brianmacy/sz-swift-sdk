# Senzing truth set (demo)

`customers.jsonl`, `reference.jsonl` and `watchlist.jsonl` are copied unchanged
from the `truthsets/demo` directory of
[Senzing/truth-sets](https://github.com/Senzing/truth-sets) (commit
`68761b692bf5cf8bf0eebd24ef5961e0bb32d25e`), licensed under the
[Apache License 2.0](https://github.com/Senzing/truth-sets/blob/main/LICENSE).

They are synthetic records with a known answer key, used by the tests and the
examples. Data sources: `CUSTOMERS`, `REFERENCE`, `WATCHLIST`.
